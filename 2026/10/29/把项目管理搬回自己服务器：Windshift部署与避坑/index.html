开源Jira替代品Windshift

发表于 2026-10-29 分类于 各种折腾 Waline： 阅读次数： 本文字数： 11k 阅读时长 ≈ 10 分钟
Windshift 是一个开源的自托管工作管理平台，定位 Jira 替代品，单二进制即可运行。

简介

什么是 Windshift？

Windshift 是一个开源的自托管工作管理平台，目标是把 Jira 的深度保留下来，同时去掉 Jira 的沉重。它用一个 Go 二进制文件打包了 Svelte 前端，默认使用内嵌 SQLite，也可以换成 PostgreSQL。

对于受够了 Jira 每年涨价、插件生态层层收费，又不想退到 Trello 那种只能看板的团队，Windshift 提供了一个折中方案：工作项、Epic、Sprint、自定义工作流、自动化、服务台、SLA、知识库、测试管理，全部内置。

主要特点

  • Jira 级的规划能力：看板、Backlog、迭代、Epic 与子任务、层级树、路线图、仪表盘一应俱全，支持工作项类型的自由配置
  • 每个工作区独立配置：工作项类型、自定义字段、界面、状态、工作流、优先级、权限都按工作区隔离，互不干扰
  • JQL 风格查询语言：内置 Windshift Query Language，过滤条件可以保存为共享集合（Collection），驱动看板、列表、日历、路线图
  • 事件驱动自动化：规则可以在事件发生时改字段、发通知、创建工作项，不需要再买 Marketplace 上的自动化插件
  • 服务台一体化：SLA 指标与目标、队列视图、预设回复、审批、客户门户全部内置，无需单独部署 Jira Service Management
  • 替代周边工具：知识库页面顶掉 Confluence，测试用例/测试运行顶掉 Xray、Zephyr，资产 CMDB 顶掉 Insight，时间跟踪也是原生的
  • Jira 导入器：内置迁移工具，支持 Jira Cloud 与 Data Center 的项目、评论、附件、worklog、看板、Sprint、自定义字段导入
  • 九种语言：含简体中文、阿拉伯语（完整 RTL 镜像布局）、日韩俄德法西葡
  • 单二进制、无外部依赖：不需要 Java，不需要 Elasticsearch 集群，约 70 MB 一个文件，树莓派也能跑
  • 开源免费：基于 AGPL-3.0 协议开源，无用户数限制，无需 License Key

应用场景

  • 团队从 Jira 迁移：受够了按人头计费与插件订阅，用内置导入器把项目整体搬过来，数据留在自己服务器上
  • 中小团队自建项目管理：五到五十人的团队，不想维护 Confluence + Jira + Xray + Insight 这一套，一个容器全解决
  • 外包与客户支持：客户门户 + SLA + 队列，对外提供工单入口，对内用同一套工作项跟踪进度
  • 研发流程闭环：关联 GitHub、GitLab、Gitea、Forgejo，分支和 PR 直接绑到工作项上，提交记录自动回流
  • 内网/合规环境：完全离线可用，数据不出机房，适合对数据主权有要求的场景

Windshift 是一个把 Jira 核心能力和周边插件压缩进单个容器的自托管方案，适合想拿回数据控制权、又不愿意在功能上做减法的团队。

注意事项

  1. /tmp 的 tmpfs 不能省：镜像是 scratch 构建，里面没有 /tmp 目录。缺少这个挂载，大附件上传会在超出 32 MiB 内存阈值后写盘失败。必须用短语法 - /tmp:exec,size=64M，Docker 默认的 noexec 会让 git 无法执行 askpass 辅助程序。
  2. 明文 HTTP 只支持 localhost：BASE_URL 填 http://192.168.0.100:8080 时，容器能正常启动，但日志会报 Failed to create CORS middleware ... insecure origin patterns，之后浏览器所有请求返回 CORS_CONFIG_ERROR。两种解法：加反向代理做 HTTPS（推荐），或在内网可信环境下显式开启 ALLOW_INSECURE_HTTP=true。
  3. Passkey 与 PWA 需要 HTTPS：明文 HTTP 下账号密码登录正常，但 Passkey 注册、PWA 安装、Web Push 推送都无法使用，因为浏览器要求安全上下文，且裸 IP 不是合法的 RP ID。
  4. USE_PROXY 只在有反代时为 true：为 true 会信任 X-Forwarded-Proto 和 X-Forwarded-For，直接暴露端口时可被伪造，导致 IP 限流与安全日志失真。用 Traefik/Nginx 时改为 true，并停止对外暴露 8080。
  5. 备份 /data 整个目录：SQLite 模式下数据库、附件、插件、生成的 VAPID 密钥都在同一个卷里。用 PostgreSQL 也别漏了附件目录，数据库备份不能覆盖它。
  6. 内存给足 2G：看板、树视图、SSE 长连接都比较吃内存。1G 能跑起来，但几十人同时在线会开始换页。WINDSHIFT_MEMORY_LIMIT_MB 与容器的 mem_limit 要成对调整。
  7. pull_policy: always 的意义：如果跟随 main 这类可变 tag，Dokploy 等平台执行 compose up -d 前不会自动 pull，可能一直跑旧镜像。固定版本号（如 v0.9.1）最稳。
  8. 中文界面已内置：九种语言里包含简体中文，登录后在个人设置里切换，不需要额外装语言包。
